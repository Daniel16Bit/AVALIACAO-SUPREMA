# Histórico recebido

Patches, instaladores, cópias antigas, testes descontinuados e documentação
anterior permanecem no ZIP original enviado pelo usuário:
`AVALIACAO_SUPREMA_3_PERIODO_DEMO_PRONTO.zip`.

Esse material não é necessário para instalar ou iniciar o projeto e não entra
no repositório. Inclui referências e cópias de bancos antigos. Não execute seus
instaladores sobre a estrutura reorganizada; consulte o mapa em `docs`.
O banco de demonstração ativo está em `AVALIACAO_SUPREMA/data` no ZIP original.
Para continuar usando os dados de demonstração, copie somente o banco ativo
para `data`, com os processos desligados. Faça backup antes de substituir
qualquer banco existente.
